The Go binding must return the parser generated from the grammar: Language() calls the C function tree_sitter_swi_prolog.

## Context

The README lists Go among the bindings `tree-sitter init` generates for this grammar. The Go binding is only useful if `Language()` hands back the parser compiled from `src/parser.c`, whose entry point is `tree_sitter_swi_prolog`. Recorded so the binding can be proved with Kibi's Go reference reader (kibi-plugin-treesitter with the kibi-lang-go pack). Reason not stated beyond the README line.
